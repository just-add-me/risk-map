# Контекст проекта для Claude

WarRisk Monitor — внутренний аналог jwla.ai: карта зон JWC Listed Areas, флот, AIS, алерты.
Пользователь — не программист, общается по-русски. Объясняй простыми словами, команды давай готовыми к вставке.

## Где что
- Описание, установка, команды: `README.md`.
- Код: `app/` (Starlette + SQLite), интерфейс: `static/` (Leaflet без сборки), запуск: Docker Compose + Caddy.
- Данные на сервере: `data/` (база, циркуляры, построенные зоны). Секреты: `.env`, в git не коммитить.

## Состояние на 21.10.2026 (v0.1)
- Логика (парсер циркуляра, алерты, API, UI, демо-AIS) проверена тестами: `python -m pytest -q tests`.
- **Не проверено на реальных данных:** `app/geo/builder.py`, построение полигонов через shapely по границам
  Natural Earth 10m. Первый запуск на сервере — его проверка. После построения зон запусти
  `docker compose exec app python -m app.geo.selftest` (17 эталонных точек) и разбери ошибки.
- Сервер пока без домена: `DOMAIN=<ip-через-дефисы>.sslip.io` в `.env`, HTTPS выдаёт Caddy.

## Правила
- Пароли, ключи (`AISSTREAM_API_KEY`, `ADMIN_PASSWORD`) пользователь вписывает в `.env` сам; не выводи их в чат.
- Перед изменениями на сервере объясняй, что сделаешь. Не удаляй `data/` и `.env`.
- Изменения кода — через git: коммит и push в `main`, на сервере обновление `bash deploy/update.sh`.
- Один процесс uvicorn: фоновые задачи (AIS, проверка LMA) не должны дублироваться.
