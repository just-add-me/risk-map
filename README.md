# FleetRisk

Внутренний сервис мониторинга флота в зонах **JWC Listed Areas** (Hull War, Piracy, Terrorism and Related Perils).
Аналог jwla.ai, работающий на вашем сервере: список судов и клиентов никуда не уходит.

## Что умеет (версия 0.1)

- **Интерактивная карта** зон из действующего циркуляра Joint War Committee (сейчас JWLA-035 от 16.09.2026).
  Изменённые и новые зоны подсвечены отдельным цветом, условные (только offshore-установки) — пунктиром.
- **Автообновление карты.** Каждые 12 часов робот открывает страницу JWC на lmalloyds.com.
  Если там появился новый JWLA, он скачивает документ, разбирает текст, перестраивает зоны
  и пишет в панель, что добавлено, изменено и исключено.
  Если какую-то зону не удалось понять автоматически, она помечается «требует проверки».
- **Зоны IBF/ITF для экипажа** (WOA — военные действия, HRA — высокий риск, ERZ — расширенный риск).
  Каждые 12 часов робот проверяет страницу IMEC, скачивает свежий PDF «IBF List of designated risk areas»,
  разбирает сроки действия и перестраивает зоны. Если IBF изменит описание границ или добавит незнакомую зону,
  она помечается «требует проверки». Когда срок списка истёк, а новой версии нет, приходит уведомление.
- **Навигационные ограничения INL (бывш. IWL)**: 21 район (Арктика, Балтика, Охотское и Берингово моря и др.).
  Сезонные районы включаются и выключаются по датам сами.
- **Порты** (~1100, Natural Earth + крупные порты Украины, Израиля, Ливана): на карте и в поиске, у каждого
  видно, в какие зоны он попадает.
- **Флоты.** Суда добавляются по MMSI вручную или файлом CSV/TXT/XLSX (колонки `mmsi`, `imo`, `name`).
- **AIS.** Бесплатный поток [aisstream.io](https://aisstream.io). Без ключа включается демо-симулятор:
  суда «ходят» через Красное море, Чёрное море, Гвинейский залив и Ормуз.
- **Уведомления в панели**: судно приближается к зоне (≤ 50 миль, с оценкой времени), вошло, вышло
  (с временем в зоне), нет AIS дольше 24 ч, вышел новый циркуляр.
  После смены циркуляра все суда пересчитываются, и вы видите, кого это затронуло.
- **Трек** судна за 3 суток, вход по паролю, HTTPS.

## Установка на сервер

Нужен VPS с Ubuntu 22.04/24.04, 2 vCPU, 4 GB RAM.

### 1. Дать серверу доступ к приватному репозиторию (один раз)

```bash
ssh-keygen -t ed25519 -f ~/.ssh/risk_map -N ""
cat ~/.ssh/risk_map.pub
```

Скопируйте выведенную строку: GitHub → репозиторий → **Settings → Deploy keys → Add deploy key**
(галочку «Allow write access» не ставить). Затем:

```bash
printf 'Host github.com\n  IdentityFile ~/.ssh/risk_map\n' >> ~/.ssh/config
git clone git@github.com:just-add-me/risk-map.git
cd risk-map
```

### 2. Установить и запустить

```bash
sudo bash deploy/install.sh
```

Скрипт ставит Docker, открывает порты 22/80/443, создаёт `.env` со случайным паролем и запускает сервис.
В конце он напечатает адрес вида `https://203-0-113-5.sslip.io`, логин и пароль.

> **Почему sslip.io?** Это бесплатный DNS: адрес `203-0-113-5.sslip.io` всегда указывает на IP `203.0.113.5`.
> Так сразу работает настоящий HTTPS-сертификат без покупки домена.
> Когда появится свой домен, замените `DOMAIN` в `.env` и выполните `docker compose up -d`.

Первый запуск: 1–3 минуты уходят на скачивание границ стран и построение зон. Прогресс виден на карте.

### 3. Подключить живой AIS

1. Зарегистрируйтесь на [aisstream.io](https://aisstream.io) (вход через GitHub) → **API Keys** → создайте ключ.
2. На сервере: `nano .env` → `AISSTREAM_API_KEY=ваш_ключ`.
3. `docker compose up -d`

## Как устроено

```
app/
  main.py              веб-сервер, API, вход, фоновые задачи
  circular/parser.py   разбор текста циркуляра JWLA → список зон
  circular/pipeline.py проверка сайта LMA, скачивание, активация новой версии
  geo/builder.py       построение полигонов (shapely): 12 миль от берега, координаты из циркуляра
  geo/zone_index.py    быстрые проверки «внутри / как далеко» (numpy)
  layers/ibf.py        список IBF/ITF: поиск PDF на сайте IMEC, разбор, шаблоны границ
  layers/inl.py        районы INL (IWL), сезоны
  layers/ports.py      порты и их зоны
  alerts.py            статусы судов и уведомления
  ais/aisstream.py     живой AIS (по 50 MMSI на соединение — ограничение aisstream)
  ais/simulator.py     демо-режим
static/                интерфейс (Leaflet, без сборки)
data/                  база SQLite, справочник судов из AIS (ships.db), скачанные циркуляры, построенные зоны (в git не попадает)
```

**Правила построения зон.** «Named Countries» — по определению JWC: порты и воды до 12 морских миль от берега.
Строим территорию страны плюс полосу 12 миль по береговой линии Natural Earth 1:10m (точность около 1 км).
Зоны «Defined Waters» строятся по координатам из текста циркуляра, а суша вычитается.

## Ограничения версии 0.1

- **Точность.** Береговая линия 1:10m: у самой границы зоны возможна погрешность около километра.
  Контуры ИЭЗ Гайаны и Венесуэлы и коридор Дона/Донца нарисованы приблизительно (помечены «≈»).
- **Покрытие AIS.** У бесплатного aisstream.io покрытие в основном береговое, в открытом океане бывают пропуски.
  На этот случай есть уведомление «нет данных AIS».
- **Нужен MMSI.** Отслеживание идёт по MMSI; если в файле только IMO, такие строки пропускаются.
- **Пользователи и уведомления.** Пока один пользователь (admin), а уведомления видны только в панели.

## Отдельные функции и как их удалить

Две функции сделаны отдельно от остального кода, чтобы их можно было безболезненно убрать:

| Функция | Файл | Метка в коде |
|---|---|---|
| Журнал заходов в зоны (заявки на доп. премию, вкладка «Журнал») | `app/zone_log.py` | `[журнал-заходов]` |
| Подозрительное поведение судов (пропал AIS, встречи в море, скачки, смена названия/MMSI) | `app/anomalies.py` | `[подозрительное-поведение]` |

Все места, где функция подключается к остальному коду, помечены её меткой (строка с меткой или блок
между «метка начало» и «метка конец»). Удалить функцию:

```bash
python3 tools/remove_feature.py журнал-заходов        # или: подозрительное-поведение
docker compose run --rm --no-deps -T -e DATA_DIR=/tmp/d -v "$PWD/app:/app/app:ro" -v "$PWD/tests:/app/tests:ro" app python -m pytest -q tests
git add -A && git commit -m "Удалена функция …" && git push origin main && bash deploy/update.sh
```

Данные функции в базе при этом остаются (не мешают). Скрипт в конце печатает SQL, которым их можно удалить.
